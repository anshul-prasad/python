However, since the turtle graphics module draws shapes graphically, and stars are typically characters, we'll simulate "stars" by writing `*` characters in positions where the turtle parts are drawn.

Because the turtle module doesn't directly support drawing text with repeated stars at arbitrary positions easily, we'll instead use the `turtle.write()` method to place stars at calculated points forming a turtle shape.

Here's the complete Python code:

```python
import turtle

def draw_star(x, y):
    """Draw a star at a specific (x, y) position using turtle.write."""
    turtle.penup()
    turtle.goto(x, y)
    turtle.write("*", font=("Arial", 14, "normal"))
    turtle.pendown()

def draw_turtle():
    # Set up the screen
    screen = turtle.Screen()
    screen.bgcolor("black")
    turtle.color("lime")  # Star color
    turtle.speed(0)
    turtle.hideturtle()

    # Coordinates for stars to form a turtle shape
    
    # Head
    head = [(0, 60), (-10, 70), (10, 70), (0, 80)]
    
    # Shell (rough circle of stars)
    shell = [
        (-30, 30), (-20, 50), (0, 60), (20, 50), (30, 30),
        (-40, 10), (-35, 20), (-25, 35), (25, 35), (35, 20), (40, 10),
        (-40, -10), (-30, -30), (-10, -40), (10, -40), (30, -30), (40, -10),
        (-25, -20), (-15, -25), (-5, -30), (5, -30), (15, -25), (25, -20)
    ]
    
    # Legs
    legs = [
        (-50, 0), (-50, -10), (-45, -20),  # left front leg
        (-50, -40), (-45, -50), (-40, -55),  # left back leg
        (50, 0), (50, -10), (45, -20),      # right front leg
        (50, -40), (45, -50), (40, -55)     # right back leg
    ]
    
    # Tail
    tail = [(-5, -60), (0, -65), (5, -60)]

    # Draw all stars
    for point in head + shell + legs + tail:
        draw_star(point[0], point[1])
    
    screen.mainloop()

draw_turtle()
```

### What this code does:
- Sets up the turtle screen with a black background.
- Defines points in (x, y) coordinates corresponding roughly to the shape of a turtle.
- At each point, it draws a star (`*`) using `turtle.write()`.
- Stars are drawn in lime green color.
- Finally, it keeps the turtle graphics window open.

### How to run:
- Copy the code into a Python `.py` file.
- Run it in an environment where the `turtle` module is supported (most standard Python installs).
- A graphics window will open and a turtle made of stars will appear.
